무진넥스 홈페이지 시안
======================

파일 구성
- index.html: 홈페이지 페이지
- style.css: 반응형 스타일
- script.js: 모바일 메뉴, 상담 카테고리 선택, 폼 시안 동작
- assets/: 제공된 로고 및 방역 작업 이미지

미리보기
1. ZIP 압축을 해제합니다.
2. index.html을 웹 브라우저에서 엽니다.
3. 인터넷 연결 시 Google Fonts의 Noto Sans KR 폰트를 불러옵니다. 오프라인에서도 기본 글꼴로 표시됩니다.

운영 전 꼭 확인할 사항
- 상담 폼은 현재 프런트엔드 시안이며, 문의가 실제로 전송되지는 않습니다.
- 실제 문의 접수를 위해 이메일 또는 서버/API 연동이 필요합니다.
- 개인정보 수집·이용 동의문과 개인정보 처리방침을 실제 운영 정책에 맞게 확정해 주세요.
- 회사 주소, 사업자 정보, 서비스별 세부 설명 및 공식 정책을 확인한 뒤 추가해 주세요.
- 대표전화 1800-6607은 모바일에서 누르면 전화 앱으로 연결되도록 설정되어 있습니다.
